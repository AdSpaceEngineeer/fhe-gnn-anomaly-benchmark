# Verified plaintext examples

`gcn_plaintext_report.json` and `tam_plaintext_report.json` record full-dataset
integration checks using `plaintext_debug`. The corresponding Markdown files
show the compact comparison tables generated by the runner.

These are plaintext diagnostics, not encrypted evaluations. Key/payload stage
names follow the common interface but do not imply cryptography. Timing and RAM
values describe these checks only; no FHE performance claim is made.

Both reports use registered frozen artifacts, fixed thresholds and test splits.
They include required thread declarations and sampled process-tree measurements.
Only reports/tables are published, not private run directories.

Memory-availability annotations were added without rerunning these historical
checks. Positive recorded peaks are retained; sample counts and completeness are
unknown. The reports retain their original execution-time source hashes.
